1. Who we are

Kairo Enterprises ("Kairo", "we", "us", or "our") is a Slovenia-registered outbound sales agency. Our public website is kairoscales.com.

This Privacy Policy explains how we handle Google user data in connection with Kairo's internal automation application (the "App"). It is intended to meet the disclosure requirements of the Google API Services User Data Policy.

2. This application

The App is an internal operations tool used only by Kairo's own team. It is not a consumer product and is not offered to the public.

The Google account connected to the App is tmarsel26@gmail.com. Kairo uses this account to automate internal operations and reporting.

3. Google user data we access

With the account owner's authorization through Google's OAuth consent screen, the App accesses the following Google user data associated with that account:

  • Gmail: send email, and read-only access to email
  • Google Drive: access to files and folders
  • Google Sheets: read and write spreadsheets
  • Google Docs: read and write documents
  • Google Forms: access form content

The App requests only the scopes needed to perform the functions described in this policy.

4. How we use Google user data

Google user data is used only to run Kairo's internal reporting and operations automations. This includes:

  • Sending internal reports and emails
  • Reading and writing Kairo's own spreadsheets, documents, and Drive folders

We do not use Google user data for advertising. We do not sell Google user data. We do not use Google user data to build or train generalized artificial intelligence or machine learning models. Google user data is used solely to provide and improve the App's features for Kairo's internal operations.

5. Sharing, sale, and transfers

We do not sell Google user data. We do not share Google user data with third parties, except for service providers that are needed to run the App:

  • Railway, which hosts the App's automation services
  • Anthropic, which is used for AI processing to generate internal reports

These transfers are made only to provide or improve the App's features. Service providers are permitted to process Google user data only as needed to perform these services for us, and not for their own independent purposes, including advertising.

6. Data protection

We take reasonable measures to protect Google user data, including:

  • Encryption of data in transit
  • Storing credentials as secured environment variables
  • Limiting access to authorized members of the Kairo team

7. Retention and deletion

We keep Google user data only for as long as it is needed to operate the App and to provide the internal reporting and operations functions described above.

The account owner can revoke the App's access to Google user data at any time at https://myaccount.google.com/permissions. After access is revoked, the App can no longer access that Google account.

To request deletion of Google user data that we have stored in connection with the App, email tian@kairoscales.com. We will fulfill deletion requests as soon as reasonably practicable, unless we are required to retain information by law.

8. Google API Services User Data Policy

Kairo's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes

If we change how the App accesses, uses, stores, or shares Google user data, we will update this Privacy Policy and take appropriate steps to notify users of the change.
